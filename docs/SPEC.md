# 名画の部屋 ── 仕様

2026年9月6日

## 何を作るか

**有名な作品だけ、有名な画家だけ**を集めた読み物サイト。250点。
1点ずつに400〜600字の解説をつける。

既存の『世界美術史』（38章・438点）とは別物である。
あちらは「美術史を通して語る」ための本で、無名の作品も年表を埋めるために入っている。
こちらは逆で、**知られている面だけを集める**。歴史の欠落は気にしない。

## 何を引き継ぐか

| 引き継ぐもの | 出どころ |
|---|---|
| 作品の基礎データ（作者・年・所蔵・Commonsファイル名） | `History-of-art/data/artworks.json` の438点から選ぶ |
| 画像解決の三段構え | `assets/js/artwork.js` をそのまま流用 |
| 用語の説明 | `History-of-art/data/glossary.json` 276語 |

書き下ろすのは**解説文だけ**。250点 × 400〜600字 ＝ 10〜15万字。

## ページ

```
/                    入口。暗い展示室
/works               250点のグリッド。時代・流派・画家・所蔵で絞り込み
/works/<id>          1点ずつ
/artists             画家一覧
/artists/<id>        人物解説＋その人の作品
/movements           流派一覧
/movements/<id>      流派の説明＋代表作
/timeline            時代順の一本道
```

作品ページ250枚は手書きしない。`data/*.json` から `tools/build.mjs` が生成する。
**生成物はコミットしない。** GitHub Actions が公開時に組む。

## 解説の型

1点を三つに割る。型を固定するのは、250点ぶん書くときに調子が崩れないようにするため。

| 節 | 分量 | 書くこと |
|---|---|---|
| **何が描かれているか** | 200〜260字 | 主題、場面、登場するもの。事実だけ |
| **なぜ有名になったか** | 200〜260字 | 何を最初にやったか。何を変えたか。誰が受け継いだか |
| **その後** | 200〜280字 | 描かれたあとに何が起きたか。受容、移動、盗難、修復、引用、再評価 |
| **ここを見る** | 3点 × 40〜60字 | 画面の**場所を指して**言う。「左端の靴」「奥の鏡」 |

1点あたり700〜850字。当初は500字で始めたが、依頼主の評価は「短い」だった（2026年9月6日）。
**「その後」を足したのは、作品を描かれた瞬間で終わらせないため**でもある。
名画が名画になるのは描かれた時点ではなく、そのあとの数百年のほうで起きる。

冒頭に一行の惹句（`lead`）を置く。グリッドの札にも使う。

## 著作権が生きている作品

ピカソ、ダリ、ウォーホルなどは、写真も**忠実な複製も**載せられない。
手で描いてもコードで描いても、複製は複製である。

そこで置くのは**構図と色面を抽象化した図**とする。
面の分割比・色数・画面の重心を正確に取り、
「この絵がどういう構造でできているか」だけを伝える図解にする。
作品そのものの代わりにはしない。かならず所蔵館の公式ページへリンクする。

`data/works.json` で `"copyright": true` を立てた作品は、
写真を探しにいかず（`noPhoto`）、`assets/figures/<id>.svg` を使う。

## 越えてはいけない線

1. **装飾を作品の事実と混同させない。** 抽象化した図を、その作品の見た目として提示しない。
2. **出典に必ず戻れる。** 所蔵館・Commons・ライセンスを全ページに出す。
3. **画像が出なくても文章は読める。** `artwork.js` が失敗しても解説は残る。
4. **虫の写真・図版は載せない。** 静物画（オランダ）と若冲に混ざるので、選定時に確認する。
5. **暗い地でも文字が読める。** 本文は地に対して十分明るく保つ。

## デザイン

**暗い展示室。** 照明を落とした美術館。地は深い墨で、作品の周りだけ光が落ちる。

- 地 `#0a0a0c` ／ 文字 `#eae6df` ／ 補助 `#8a857c`
- 額をつけない。作品は暗がりに浮かぶ
- 流派ごとに差し色を1色だけ持たせる。地の色は変えない
- 見出しは明朝、本文はゴシック
- 作品ページは上半分が図版だけの暗い間。スクロールで解説が下から現れる

## 進め方

1. 骨格（全ページ・生成スクリプト・デザイン）── **いまここ**
2. 代表20点を満額の解説で入れる
3. 見てもらう。デザインと文の調子を確定する
4. Codex にレビューを回す
5. 残り230点を積む
